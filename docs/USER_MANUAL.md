# 用户使用手册

## 启动系统

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

打开实际监听地址，例如 `http://127.0.0.1:8010/`。

启动后可访问 `/health` 核对当前实际模型。默认部署为
`models/expanded-ppe-yolov8s-hardcase12.pt`、输入尺寸 640；若显示
`fallback` 或旧权重，先检查 `.env` 的 `MODEL_PATH` 并重启服务。

## 登录

开发账号：`admin` / `admin123`。

登录成功后会进入“监控总览”，加载摄像头、告警事件、统计指标、等级构成和实时通道状态。

## 图片检测

1. 点击左侧“智能检测”，在“图片安全检测”工作区拖拽或选择图片。
2. 可选绑定摄像头，用于读取该摄像头的危险区域配置。
3. 点击“开始智能检测”。
4. 页面显示检测画面、人员/PPE 分类计数、检测明细、原始 JSON（折叠在技术详情中）和告警判定。

## 视频任务

1. 在“智能检测”的“视频异步分析任务”区域选择 MP4/AVI/MOV/MKV 文件。
2. 点击“提交视频任务”。
3. 右侧任务控制台显示 queued/running/completed 状态和进度条。
4. 视频推理依赖 `opencv-python`，未安装时任务会失败并显示错误原因。

## 查看任务结果

1. 点击左侧“任务中心”，在已完成任务的“结果”列点击“查看可视化结果”。
2. 图片任务显示标注图片、人员/PPE 数量和事件摘要；视频任务显示浏览器可播放的 WebM/VP8 结果视频。
3. “查看原始 JSON”仅用于论文复现、接口调试和逐帧数据检查，不作为课堂演示的主要结果页。

## 摄像头与危险区域

1. 点击左侧“设备与区域”，新增摄像头，填写名称、source 和安装位置。
2. 选择摄像头，在画布中依次点击危险区顶点；需要精确调整时编辑坐标 JSON。
3. 保存危险区后，图片/视频推理绑定该摄像头即可启用越界规则。

危险区示例：

```json
[{"x":160,"y":260},{"x":500,"y":260},{"x":500,"y":470},{"x":160,"y":470}]
```

## 告警处理

- `确认`：将事件状态改为 `acknowledged`。
- `关闭`：将事件状态改为 `resolved`。
- 有证据截图的事件可点击“查看截图”打开证据弹窗。

## 现场演示建议

推荐按“健康检查 → 登录 → 图片检测 → 摄像头与危险区 → 告警处理 → 视频任务 → 指标回看”的顺序演示。完整操作脚本、每一步预期现象和备用 fallback 场景见 `docs/DEMO_GUIDE.md`；答辩讲解话术见 `docs/PRESENTATION_SCRIPT.md`。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 页面显示“服务连接中” | 确认服务已启动并访问实际端口的 `/health`，例如 `http://127.0.0.1:8010/health` |
| 登录后数据为空 | 点击刷新，或清除浏览器旧 token 后重新登录 |
| 图片没有检测框 | 检查 `.env` 的 `MODEL_PATH`；模型缺失时会进入 fallback，空白图片也可能没有真实 YOLO 检测框 |
| 视频任务失败 | 检查文件扩展名和 OpenCV 安装，查看任务的 `error_message` |
| 证据链接打不开 | 确认 URL 使用 `/results/`，不要直接把 Windows 反斜杠路径粘贴到浏览器 |
