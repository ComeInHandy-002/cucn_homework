# 现场展示与演示手册

## 演示目标

用 5–8 分钟完整展示“检测 → 跟踪/规则 → 告警 → 处理 → 结果回看”闭环。演示只使用本地文件，不接入 RTSP、不做人脸识别、不控制设备。

## 演示前准备

1. 在项目根目录执行 `.\scripts\setup.ps1 -SkipInstall`。
2. 运行前先访问 `/health`，确认 `model_available=true`，并核对返回的 `model_path` 与
   `image_size`；当前默认部署副本为 `models/expanded-ppe-yolov8s-hardcase12.pt`、
   输入尺寸 640。若返回旧权重或 fallback，先按 `docs/SETUP.md` 修正配置并重启。
3. 先检查端口：`Get-NetTCPConnection -LocalPort 8000 -State Listen`。若已有其他应用占用，使用 8010 启动：`.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010`。
4. 浏览器打开实际地址，例如 `http://127.0.0.1:8010/`。不要把占用中的 8000 当成本项目页面。
5. 从 `data/demo/selected/images/` 准备图片：首选 `01_光伏作业_安全帽背心.jpeg`，违规对照使用 `05_缺少安全帽_有背心.jpg`。
6. 从 `data/demo/selected/videos/` 准备视频：合规检测使用 `01_工程师安全帽背心_合规.mp4`，违规检测使用 `02_施工人员缺安全帽_违规.mp4`，跟踪展示使用 `03_施工人员行走_跟踪.mp4`。
7. 打开 `data/demo/selected/素材总览.jpg` 快速确认素材；逐文件来源、许可证、尺寸和哈希见同目录 `README.md` 与 `manifest.json`。

## 现场操作脚本

### 1. 健康检查（约 20 秒）

指出右上角健康状态，说明服务已经加载 Ultralytics 训练权重；若显示 fallback，说明模型文件缺失，演示规则流程仍可继续，但不要把 fallback 当模型结果。

### 2. 登录和总览（约 45 秒）

输入 `admin` / `admin123`，点击“登录”。说明 JWT 登录后才允许访问业务接口。登录后先停留在“监控总览”，展示四张指标卡、告警类型环图、等级构成、推理服务状态、最新事件和监控点运行状态；右上角实时通道变为在线。

### 3. 真实图片检测（约 90 秒）

点击左侧“智能检测”，在图片工作区的“快速载入演示素材”下拉框选择 `01_光伏作业_安全帽背心.jpeg`，点击“载入图片样例”，再点击“开始智能检测”。页面会自动把归档文件放入上传框并显示文件名、大小和预览图，不需要手动查找路径。完成合规样例后可换用 `05_缺少安全帽_有背心.jpg` 展示违规对照。展示四件事：

- 检测画面：标注预览图和检测状态。
- 目标计数：人员、安全帽、反光背心分类统计。
- 明细表：类别、置信度、轨迹 ID；原始 JSON 可展开查看。
- 事件判定：如果规则判定违规，会出现在告警中心并保存证据路径。

强调：单张图片使用 1 帧确认；视频使用连续 3 帧确认。

### 4. 摄像头与危险区域（约 75 秒）

点击左侧“设备与区域”，新增摄像头“车间A”，source 填 `local`，位置可填“A 区北侧”。在右侧画布依次点击 3 个以上顶点，画出红色多边形；也可在“坐标数据”中精确修改：

```json
[{"x":160,"y":260},{"x":500,"y":260},{"x":500,"y":470},{"x":160,"y":470}]
```

点击“保存并启用危险区域”。说明系统使用人员框底部中心点判断是否进入多边形，而不是使用整个框，减少跨边界误报。

### 5. 告警闭环（约 75 秒）

点击左侧“告警中心”，按“待处理”或事件类型筛选。展示事件类型、严重等级、时间和证据截图；点击“查看截图”打开证据弹窗，点击“确认”将状态改为 `acknowledged`，再点击“关闭”改为 `resolved`。说明同一人员、同一规则在 10 秒冷却期内不会重复入库。

### 6. 视频任务（约 60–90 秒）

回到“智能检测”，在视频工作区选择 `01_工程师安全帽背心_合规.mp4` 并点击“载入视频样例”，确认文件名和大小出现后点击“提交视频任务”。指出右侧任务控制台会经历 `queued → running → completed`，进度来自视频帧处理比例；完成后点击“查看结果”，结果视频和 JSON 保存在 `results/`。时间充足时再用 `02_施工人员缺安全帽_违规.mp4` 展示违规规则，或用 `03_施工人员行走_跟踪.mp4` 讲解 `track_id` 稳定性。

### 7. 任务与实验回看（约 60 秒）

 点击左侧“任务中心”，展示图片/视频任务历史、状态筛选、进度条和结果链接，说明任务记录会持久化到数据库，不会因为离开检测页丢失。再点击“模型实验”，展示合并集 Expanded PPE + Kaggle PPE 的 train/val/test 数量（8276/2184/1163）、标注框校验（20695/5111/3047），以及 E7 hard-case 12 epoch 当前模型、E6 8 epoch 历史对照、E8 video150 30 epoch 候选、旧 Expanded PPE 10/5 epoch 与 smoke 指标；所有行均注明数据版本、训练轮数和独立 test split。页面中带“当前部署”的仍是 E7，E8 只作为候选对照，不现场切换。

当前 8 张内置图片的可复现回归记录在 `results/demo-regression-hardcase12.json`。三张用户抽查原图的硬性门禁位于 `results/hardcase-regression-hardcase12.json`；两段视频定向回归位于 `results/video-regression-hardcase12.json`。这些结果可证明已知演示场景行为，但都不是独立模型精度指标。

### 8. 收尾讲解（约 30 秒）

 回到“监控总览”，说明指标卡和最新事件已随操作同步变化，系统完成了从模型检测到事件持久化的闭环。最后主动说明本阶段正式验收边界：当前已完成 E7 部署、E8 候选训练及门禁复核；80 epoch、正式 720p/15 FPS、300–500 帧独立自建场景测试和跟踪/规则消融仍需继续补充，不能用目标值替代实测值。

## 备用演示：无模型或需要稳定触发告警

若现场模型加载失败，设置 `.env`：

```text
MODEL_PATH=models/missing.pt
FALLBACK_SCENARIO=no_ppe
```

重启服务后上传任意扩展名合法的图片，fallback 会生成中心人员且不生成 PPE，从而稳定展示 `no_helmet` / `no_vest` 告警、事件确认和指标变化。演示时必须明确这是流程演示，不是模型性能结果。

## 现场故障处理

| 故障 | 快速处理 |
| --- | --- |
| 端口 8000 被占用 | 关闭旧 uvicorn，或改用 `--port 8010` 后访问对应地址 |
| 页面无法加载 | 先访问 `/health`，确认服务进程正常 |
| 登录失败 | 使用开发账号，或删除 localStorage 中的 `safety_token` 后重试 |
| 图片无框 | 确认使用数据集真实图片；空白图片可能没有模型检测结果 |
| 视频失败 | 使用 MP4，确认 OpenCV 可导入，查看任务 `error_message` |
| Docker 不可用 | 先使用 SQLite 本地演示；Docker Desktop daemon 恢复后再演示 PostgreSQL |

## 讲解禁区

- 不把 smoke baseline 或定向 hard-case 回归说成独立泛化精度；E7 12 epoch、E6 8 epoch和旧集 10/5 epoch 指标必须同时说明数据版本、训练轮数和 test split。
- 不把 fallback 结果说成 YOLO 检测结果。
- 不声称已经完成 720p/15 FPS，除非现场有独立测量记录。
- 不展示真实个人身份信息；样例只用于安全作业目标检测。
